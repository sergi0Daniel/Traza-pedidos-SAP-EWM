La aplicación utiliza información de demostración. Para conectar SAP EWM, TI debe proporcionar el endpoint autorizado, el mecanismo de autenticación y el formato de respuesta.

Información requerida para habilitar la conexión

01Endpoint autorizado

Dirección del servicio REST u OData definida por TI.

02Autenticación

Usuario técnico o mecanismo de autenticación aprobado.

03Formato de datos

Campos de pedido, posiciones, tareas, DT, eventos y ubicaciones.

04Prueba controlada

Validar un pedido autorizado y contrastar la respuesta con SAP EWM.
